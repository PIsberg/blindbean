## Project

BlindBean is a Java 26 library that hides Homomorphic Encryption behind annotations. Developers mark fields with `@Homomorphic` and operate on encrypted values through generated wrapper proxies. Paillier is implemented in pure Java (Vector API); BFV/CKKS bridge to Microsoft SEAL 4.3 via a C++ DLL over Project Panama FFM (no JNI).

## Start here

```bash
./mvnw clean install -B -Dblindbean.native.path=build-native
```

Requires **JDK 26-ea**. `JAVA_HOME` must point at it, or surefire forks the wrong JVM and the run
dies on "class file version 70.0". On Windows use `mvnw.cmd` and
`-Dblindbean.native.path=build-native/Release`. Tests that touch BFV/CKKS need the native DLL built
first; Paillier, processor and JUnit-extension tests do not. Full commands, the native cmake build
and the example module: **`docs/BUILD-AND-TEST.md`**.

## Invariants

Expensive to get wrong, so they stay here rather than behind a link. The detail is in the file named
after each one.

- **Proxies are source-generated, never reflective.** Do not add runtime reflection or bytecode
  weaving. (`ARCHITECTURE-LAYERS`)
- **Do not lower poly modulus degree below 8192 or weaken coeff modulus** without an explicit
  request. Parameters target 128-bit security. (`ARCHITECTURE-LAYERS`)
- **`FheContext` is `AutoCloseable`.** Use try-with-resources or leak native heap.
  (`ARCHITECTURE-LAYERS`)
- **`math`, `context` and `async` ship together as `-runtime`.** The cycle is real; do not try to
  separate them. (`MODULE-LAYOUT`)
- **`processor` depends only on `annotations`.** A consumer's compile path must not pull the
  runtime, the native library or the Vector API. (`MODULE-LAYOUT`)
- **All tests live in `blindbean-tests`,** not in the library modules. (`MODULE-LAYOUT`)
- **Tests that need the DLL carry `@Tag("native")`,** on the `@Nested` class when only part of a
  suite needs it. An untagged one breaks the Linux fast gate. (`CI-NOTES`)
- **Never use CKKS for money.** It is approximate; `BigDecimal` on Paillier is the exact option.
  (`FIELD-TYPES`)
- **Numeric decodes go through `PaillierMath.decryptSigned`;** strings and `byte[]` keep plain
  `decrypt`. (`FIELD-TYPES`)
- **Generated guardrail blocks are never hand-edited.** Change the `@AI*` annotation and recompile.
- **A Central release is irreversible.** The tag must match `<version>` in `pom.xml`, and
  `autoPublish` stays `false`. (`RELEASING`)
